# Apache Hive : HPL/SQL - LEN Function

LEN function returns the length of the specified string expression in characters, **excluding** the trailing blanks.

**Syntax**:

```
LEN(string_expression); 
```

**Return Data Type:**

STRING

**Example:**

```
LEN('Abc ');
---
3
```

**Compatibility**: Microsoft SQL Server
