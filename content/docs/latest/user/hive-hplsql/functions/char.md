# Apache Hive : HPL/SQL - CHAR Function

CHAR function converts a number to string.

**Syntax**:

```
CHAR(num_expression); 
```

**Return Type:**

STRING

**Example 1:**

```
CHAR(1000); 
--
1000
```

**Compatibility**: IBM DB2
